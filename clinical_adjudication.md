# Old ↔ New Clinical Dataset Comparison — Adjudicated

## 2026-09-03 — Coding-scheme revision: ConfoundYN split, PVal replaced

Per the 2026-09 coding-scheme revision already reflected in
`clinical_trials/scripts/_lib.py` `CARRIED_FIELDS` (design §10 / codebook §11),
`clinical_master.csv` was updated to match: `ConfoundYN` dropped and split into
`MediatingYN` / `ModeratingYN`; `PVal` dropped and replaced by
`HypothesisTestReportedYN`. Values for the three new columns came from a v3
extraction run, initially merged into the live master by `StudyID` as a
one-off patch (no other column, and no row's `EligibleYN`, was touched).

That patch has since been superseded: the same field swap was spliced
directly into all 49 live `clinical_trials/raw_responses/*_response.json`
files (data.article and, where present, rationale.article), sourced from the
same v3 run, and `clinical_master.csv` was then regenerated for real via
`clinical_trials/scripts/merge_validate.py`. Each touched raw-response file
carries a `SchemaRevisionNote` rationale entry disclosing that it is now a
hybrid of two extraction runs (v2 for every other field, the noted v3
`PromptVersion` for these three) — see that note, per file, for the exact
provenance. The regenerated master was diffed against the prior one: zero
changes outside the intended column swap, same 42-study eligible cohort
(32/6/4). A future `merge_validate.py` rebuild will now reproduce this schema
correctly on its own; no separate re-merge step is needed. This is not a
per-study old-vs-new disagreement (the three new fields have no "Old"
counterpart to adjudicate against), so it isn't logged as a table row below;
recorded here instead since it changes the master's schema and, unusually,
the raw-response source files themselves.

Independent adjudication of every per-study disagreement between the frozen hand extraction ("Old") and the new automated master ("New") in `clinical_trials/outputs/old_new_comparison_report.md`, against the actual source paper text in `clinical_trials/inputs/text/`.

## Scope

- **All 44 studies** with per-study disagreement rows, across Alcohol (33), Smoking (4), and Opioid (7).
- **All fields except `InterventionDescription`** (excluded per your instruction — that free-text drug/dose/protocol field stays flagged for separate human review, out of scope here).
- **Substance identity** = the binary substance-flag columns (e.g. Mescaline, MultiplePsychedelic, Ibogaine, Ketamine), not the free-text intervention description.
- **Condition treated**: the `Condition` column has 100% old/new agreement — no per-study disagreements exist for it, so it doesn't appear in the table below.
- One extra row was added for **Denson 1970**, whose case is not a field-value disagreement but a full eligibility dispute (class X2 in the report): the old dataset includes it, the new automated screen excludes it. This determines whether the study belongs in the evidence base at all, so it's adjudicated alongside the field-level rows.
- The report's class codes (X3/X4/X5/E2/E3/E4) were the script's provisional guess about *why* a cell disagreed — they were not treated as ground truth. Every row here was independently re-checked against the source text.
- Work was parallelized across 5 reviewers (one per ~9-study batch), each reading the full source text for their assigned studies before adjudicating.

## Notable findings

- **Bowen 1970** — `RandomizationYN`, `BlindingYN`, and `Double+Blind` all favor **Old**. Experiment II used genuine random dose assignment and an explicit double-blind procedure (dose withheld from all parties until a year after outcome data collection); this is corroborated externally — Bogenschutz et al. 2015 lists Bowen 1970 among "the six published randomized trials of LSD treatment of alcoholism" (Krebs & Johansen 2012). The New extraction appears to have miscoded all three fields as 0.
- **Sessa 2019** — `RandomizationYN` favors **New** (0). The paper is explicitly described as an open-label, uncontrolled safety/tolerability case series; Old's "1" is a miscode.
- **Jovaisa T 2006** — substance-identity flags were swapped in Old: `Ibogaine=1/Ketamine=0`. The paper is entirely about IV ketamine as an anesthesia adjunct for opioid-antagonist induction; ibogaine is never mentioned. **New is correct on both flags.**
- **Smith 1958** — `Mescaline` and `MultiplePsychedelic` both favor **New**: the paper explicitly used LSD and mescaline (0.5 g) across the sample, with at least one patient receiving both. Old miscoded both as 0.
- **Sample-size discrepancies split unpredictably by study — no blanket rule applies:**
  - D.C. Mash 2000: **Old's 27** is correct (explicit in text: "27 subjects"); New's blank is a pipeline extraction failure (one of the two BLOCK-flagged cases in the report).
  - Savage 1973: **New's 73** is actually correct (one of the 37 treatment-arm patients died before the 12-month primary endpoint, so the paper's own analysis uses 36+37=73, not the 74 originally randomized) — the opposite resolution from D.C. Mash 2000 despite an identical BLOCK flag.
  - Das 2019: **Old's 90** is correct (total randomized/analyzed N); New's 30 is only a single arm's count.
  - Terasaki 2022: **Old's 44** is correct (paper's own stated ITT N: "we consented and randomized 44 participants"); New's 30 is a derived 2-of-3-arm subset.
  - MacLean 1961: **New's 61** is correct; Old's 100 incorrectly pools in 39 non-alcoholic psychiatric patients.
  - Rothberg 2021: **New's 40** is correct (all-enrolled primary-analysis N); Old's 35 is a sub-sample used only for a secondary mediation analysis.
  - Grabski 2022: **Old's 96** is correct (explicit ITT N in text); New's 89 derives from a figure caption's sub-analysis count.
  - Tomsovic 1970: **Unclear** — the paper never states one overall analyzed N; both 192 and 58 are subgroup constructs.
- **Denson 1970 eligibility (X2)** is well-supported: the new automated screen is right that this study reports no alcohol-consumption, abstinence, craving, or validated SUD outcome anywhere, and pools alcoholics with neurotic patients in the same analysis. Recommend excluding it from the evidence base, consistent with the new pipeline.
- **`Outcome` field pattern**: many disagreements are the same statistic in different notation (scored Equivalent), but a meaningful subset are genuinely *different* statistics or timepoints from the same paper — e.g. Bogenschutz 2015's `d = 1.383` is a secondary weeks-25–36 contrast while `26.0` is the pre-specified primary weeks-5–12 endpoint (New is correct); Terasaki 2022's Old value is more complete because it preserves a second treatment-arm comparison New drops entirely. Each Outcome row required reading the paper's own designated primary endpoint, not a blanket old-vs-new rule.
