# PROJECT_PLAN.md

USPSTF Evidentiary-Gap Analysis: Psychedelic Interventions for Substance Use Disorders

This document is the source of truth for outstanding analytic and engineering tasks. It is written for Claude Code to execute task-by-task. Every task lists explicit inputs, outputs, and acceptance criteria.

---

## 1. Project overview

**Goal.** Produce the Results section (tables and figures only — prose is written by the human author) of a manuscript that maps the existing psychedelic-trial evidence base for three substance use disorders (alcohol, tobacco/smoking, opioid) against USPSTF-style evidentiary requirements, identifies coverage gaps, and benchmarks effect sizes against USPSTF-recommended comparator interventions.

**Scope.** Three condition-specific datasets, hand-coded against a shared 52-variable codebook (`opus_extraction_prompt.md`, in the project Knowledge), produce one integrated manuscript. All Results outputs are stratified by **condition × era × substance class** where the cell counts permit.

**Reproducibility requirement.** A peer reviewer cloning the repo and running `python run_pipeline.py` against the pinned versions in `requirements-lock.txt` must reproduce every published table and figure byte-for-byte (modulo OS-level font rendering for the docx files).

## 4. Conventions

### 4.1 CLI

Every refactored or new script accepts a `--condition` flag taking `alcohol | smoking | opioid | combined`, plus an optional `--output-dir` defaulting to the project root. Example:

```bash
python scripts/clean_dataset.py --condition alcohol
python scripts/tier1_hedges_g.py --condition smoking
python scripts/descriptive_analyses.py --condition combined
```

Use `argparse`. Scripts must exit with non-zero status on any error.

### 4.2 Naming

- Output files start with the capitalized condition name: `Alcohol_…`, `Smoking_…`, `Opioid_…`, `Combined_…`.
- Underscore-prefixed `_lib.py` and `_config_<condition>.py` are not intended to be run as scripts; they are imported.

### 4.3 Era and substance class

Both refactored scripts and new scripts must apply these classifications consistently:

**Era**

| Year | Bucket |
|---|---|
| < 1980 | `Pre-1980` |
| 1980–2009 | `Gap` (currently empty across all conditions) |
| ≥ 2010 | `2010+` |

**Substance class** (mutually exclusive; assigned to whichever single substance the study used; for studies using multiple, assigned to the row's first `1` in the order below)

| Class | Substances (codebook columns) |
|---|---|
| Classical psychedelic | Psilocybin, LSD, Mescaline, Ayahuasca, Ibogaine, OtherPsychedelic |
| Entactogen | MDMA |
| Dissociative | Ketamine |
| Cannabinoid | Cannabis |
| Multi-substance | (use only when `MultiplePsychedelic == 1` and no single primary substance is identifiable) |

Substance class is computed in `_lib.py` as `primary_substance_class(row)` and added as a column to the cleaned datasets.

### 4.4 Style

- Python 3.11+ syntax; type hints on all public functions in `_lib.py`.
- Tables in docx: Arial 10pt body, 11pt headers, `clear` shading, US Letter, 1" margins (matching `descriptive_analyses.py`).
- Figures in PNG at 220 DPI, white background, colorblind-safe palette already in `tier1_hedges_g.py`.
- All scripts deterministic. Any stochastic step (Task 8 power simulation) seeds with `numpy.random.default_rng(20260101)` and exposes `--seed` as an override.

### 4.5 Missingness conventions

These are inherited from `clean_alcohol_dataset.py` and apply to all conditions:

- `.` → `NaN` globally on string columns.
- Binary `3` → `'Does not apply'` only in the binary columns enumerated in `_lib.py:BINARY_COLS`.
- Continuous columns where `3` is a real value (e.g., `Followup in months` = 3 months) are not touched by the binary recode.
- Strict-gap interpretation in heat maps: missing/`'Does not apply'` counts as not met. Footnotes say so.

## 5. Schemas the human author supplies

### 5.1 `data/benchmarks/USPSTF_Benchmarks.xlsx`

One row per benchmark intervention. Required columns:

| Column | Type | Notes |
|---|---|---|
| `condition` | str | One of `alcohol`, `smoking`, `opioid` |
| `intervention_name` | str | e.g., "Behavioral counseling for unhealthy alcohol use (USPSTF Grade B)" |
| `hedges_g` | float | Point estimate on the same scale as Tier 1 outputs |
| `ci_lo` | float | 95% CI lower bound |
| `ci_hi` | float | 95% CI upper bound |
| `n_studies` | int (optional) | Number of studies in the source meta-analysis |
| `n_participants` | int (optional) | Pooled N |
| `source_citation` | str | Author Year format (e.g., "Tan 2022") |
| `uspstf_grade` | str (optional) | A, B, C, D, I |
| `notes` | str (optional) | Free text |

Multiple benchmarks per condition are allowed (one per recommended intervention). The forest-plot script (Task 6) overlays each as a vertical reference band.

### 5.2 `data/rob/RoB_Assessments_<condition>.xlsx` (optional input; otherwise generated)

If provided, one row per study. Required columns:

| Column | Type | Notes |
|---|---|---|
| `study_id` | str | `Surname Year` matching the cleaned dataset |
| `tool` | str | `RoB 2` (randomized) or `ROBINS-I` (non-randomized) |
| `domain_1` … `domain_n` | str | `Low` / `Some concerns` / `High` per RoB 2 (5 domains) or ROBINS-I (7 domains) |
| `overall` | str | `Low` / `Some concerns` / `High` |
| `notes` | str | Rationale (optional) |

Domain definitions:

- **RoB 2** (5): Randomization process; Deviations from intended interventions; Missing outcome data; Measurement of outcome; Selection of reported result.
- **ROBINS-I** (7): Confounding; Selection; Classification of interventions; Deviations; Missing data; Measurement of outcomes; Selection of reported result.

If absent, Task 5 generates a starter template populated with `Some concerns` defaults; the human author finalizes by reviewing each PDF.

### Task 8 — Sensitivity analyses and trials-needed simulation

**Prerequisites.** Tasks 4 and 5 complete (Tier 1 results and RoB assessments available).

**Goal.** Two analyses requested in the manuscript outline:

1. **Sensitivity analysis: high-quality subset.** Recompute every quantitative result (effect-size summary, descriptive table headline numbers) restricted to a "high-quality" subset.
2. **Trials-needed simulation.** Estimate the sample size and number of trials required for cumulative meta-analytic precision to reach a useful CI width, under several assumed true effect sizes.

**Inputs.**
- `tables/<Condition>_Tier1_HedgesG.xlsx` (all available).
- `data/rob/RoB_Assessments_*.xlsx` (all available).
- `data/benchmarks/USPSTF_Benchmarks.xlsx` (optional, for assumed-effect-size scenarios).

**Outputs.**
- `tables/Sensitivity_Analyses.docx` containing:
  - **Table A.** Comparison of effect-size summary (median g, IQR, % positive) full sample vs. high-quality subset, by condition.
  - **Table B.** Comparison of methodological-quality and outcome-domain percentages, full sample vs. high-quality subset.
  - **Table C.** List of studies in the high-quality subset with their RoB rating.
- `tables/TrialsNeeded_Simulation.docx` containing:
  - **Table D.** Per-condition projected required sample size, for each scenario, to reach a target CI half-width on g (default target: ±0.10).
- `figures/TrialsNeeded_PowerCurves.png` — power curves for new RCTs at α=0.05, two-sided, 1:1 allocation, varying true g.

**Definitions.**
- **High-quality subset** (default — overridable via CLI flags): RoB 2 overall = `Low`, OR (`RandomizationYN == 1` AND `Double+Blind == 1` AND `Comparator == 1` AND `Power == 1`). The CLI flag `--quality-criterion {rob_low, rct_strict, both}` lets the author tighten/loosen.
- **Trials-needed scenarios** (default — overridable):
  - Scenario A: assumed true g = current Tier 1 median for the condition.
  - Scenario B: assumed true g = USPSTF benchmark intervention's reported g (from the benchmarks file).
  - Scenario C: assumed true g = 0.30 (a generic minimal clinically important effect).
  - Each scenario assumes 15% dropout, fixed-effect inverse-variance pooling, target half-width 0.10 on the pooled estimate.
- **Power simulation method.** For each true g in {0.2, 0.3, 0.5, 0.8} and per-arm n in {25, 50, 75, 100, 150, 200, 300}, simulate 5,000 two-sample t-tests under the assumed normal-effect model; record empirical power. Random seed: `default_rng(20260101)`. Override via `--seed` and `--n-sims`.

**Implementation.**
- `scripts/sensitivity_analyses.py` and `scripts/trials_needed_simulation.py` are separate scripts; each accepts `--condition`. The combined manuscript figures/tables use `--condition combined`.
- Power-curve figure: one panel per condition (or one combined panel if cell counts are too small), x-axis = per-arm n, y-axis = power, colored lines = assumed true g.

**Acceptance criteria.**
- The high-quality subset is non-empty for at least the alcohol condition (current data has 2010+ Bogenschutz, Das, Nicholas trials that should pass `rct_strict`).
- The simulation is fully reproducible — running the script twice produces identical numeric outputs given the same `--seed`.

## 9. Open questions / known uncertainties

These are flagged for the author to resolve when the relevant task starts:

1. **Smoking and opioid extraction date.** No timeline specified; tasks dependent on these datasets remain blocked until the files appear in `data/`.
2. **Combined manuscript table orientation.** Some of the combined tables may need landscape orientation when 4 condition columns × 2 era subcolumns are present. Final orientation choice deferred to Task 7 implementation; if cells overflow, switch to landscape and note in the docx.
3. **Power-simulation default target precision.** Half-width 0.10 on Hedges' g is a defensible default but is not based on a USPSTF-specific criterion. Author may want to tighten (e.g., 0.05) for a more demanding target.
4. **High-quality subset definition.** Default uses `Low` RoB OR strict RCT criteria (see Task 8). Whether `Some concerns` should also pass is not yet decided; `--quality-criterion` flag allows choosing at runtime.
5. **Multi-substance studies.** Codebook's `MultiplePsychedelic` flag exists but `primary_substance_class` defaults to the first matched single-substance column. If a study genuinely uses two psychedelics in one arm, the assigned class will be the alphabetically-first one. Acceptable for current dataset (no such cases in alcohol); may need revisiting for smoking/opioid.
